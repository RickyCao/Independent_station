# FYX 代数负数教学大纲（初一 · 专项补救）

> 关键判断：她表面错在"去括号/绝对值"，根子其实是"负数概念"没建立。大纲必须**先回到有理数基础重建，再往上打**，跳过基础直接刷题治标不治本。

## 一、先诊断（第 1 次课，30 分钟）

按顺序给题，哪层开始崩就从哪层补。**每题都要让她"说出为什么"**，记下原话，判断是"规则背错"还是"概念没通"。

| 层 | 题目 | 标准答案 |
|---|---|---|
| 相反数 | -3 的相反数？-(-5)=? | 3；5 |
| 负号=减号 | 把 5-3 改写成加法；把 -3 改写成"0 减 3" | 5+(-3)；0-3 |
| 负数加减 | (-3)+(-2)；5-(-3)；(-5)-(-3) | -5；8；-2 |
| 负因数分配 | -1×(3x-3)；-(3x-3) | -3x+3；-3x+3 |
| 去括号 | (2x+1)-(3x-3) | -x+4 |
| 绝对值 | |-5|；|5|；x=-4 时 |x|；x=-4 时 |x-1| | 5；5；4；5 |

## 二、两条核心主线（贯穿全程）

1. **"-"只有一种本质：相反数**。减号 = 负号，因为 **a − b = a + (−b)**；−3 = 0 − 3。
2. **去括号 = 分配律，不是玄学规则**。−(...) 就是 −1 乘括号，所以每个符号都翻。

这两条内化了，她 80% 的符号错会自己消失。

## 三、六个模块（递进，过关才进下一层）

### 模块 1：把"-"的三种身份统一（最关键）
- **目标**：理解负号 = 减号，减法就是加相反数。
- **讲法**（多感官）：数轴（相反数 = 关于 0 的镜像）；电梯/楼层（地上 +3、地下 -2）；欠债（-3 = 欠 3 块，"减去欠款" = 加回 3）；铁律 a − b = a + (−b)。
- **练习**：把每道减法先改写成加法再做。
- **常见错误**：5−(−3) 算成 2。用"减负 = 加正"（还掉欠款 = 多出钱）纠正。

### 模块 2：负数四则的直觉（打地基）
- 加减：数轴移动法。
- 乘除：符号规则（正正得正 / 正负得负 / **负负得正**），用"相反数的相反数回到本身"讲负负得正。
- 幂（提前埋雷）：**(-3)² = 9，但 -3² = -9**。

### 模块 3：分配律 + 负因数（去括号的本质）
- **目标**：理解 -(3x-3) = -3x+3 的"为什么"。
- **三个角度轮着讲**：①乘法 -(3x-3) = -1·(3x-3) = -1·3x + (-1)·(-3) = -3x+3；②减法 = 0-(3x-3) = 0-3x+3；③实物"去掉(3x-3)这一整包" = 去掉 3x、再去掉 -3（即加回 3）。
- **关键结论**：括号前是负号，**里面每一项都要变号**。

### 模块 4：去括号系统化（把规律固化）
- +(a+b−c) → 直接去，符号不变；−(a+b−c) → 全变号 → −a−b+c。
- 混合：(2x+1)−(3x−3)，把中间减号看成"加(−(3x−3))"，再合并同类项。

### 模块 5：绝对值（先数后式）
- **目标**：绝对值 = 到 0 的距离，永远 ≥ 0。
- 纯数：|-5|=5、|5|=5，用数轴距离讲，别背。
- 含字母（重灾区）：**头号陷阱** x<0 时 |x| = −x（这个 −x 其实是正数）；|x−1| 分 x≥1 和 x<1 讨论；养成"先判断里面正负"的习惯。

### 模块 6：综合 + 错题复盘
- 去括号、绝对值、合并同类项混着出小综合题。
- 错题本：每错一题写"我错在哪一步 + 正确思路"。

## 四、贯穿技巧

- **必须让她"说出为什么"**：能口述才算真懂，只做对不算。
- **一题三法**：同一道 -(3x-3) 用乘法/减法/实物轮着讲。
- **强制改写**：要求她每一步都写 a−b = a+(−b)，直到自动化。
- **图形化**：数轴 + 彩色卡（正数一色、负数一色）。
- **间隔重复**：每天 3-5 道符号题，一周后回测。

## 五、过关标准（判断是否真学透）

- 能不看规则解释：为什么 5−(−3) = 8
- 能口述 -(3x-3) = -3x+3 的**三个理由之一**
- 能做对：x=−4 时 |x−1| = 5，并说明为什么这里的 −x 是正的
- 混合题**连续 10 道符号不错**

## 六、节奏建议

- 约 **4-6 次课**（每次 40-60 分钟），模块 1-2 可能要占 2 次课，**别赶**。
- 每次课留 3-5 题当天练，下次课前先回测上次内容再推进。
