# 绝对值方程 · 零点分段法（FYX 当前阶段）

> 针对题型：|2x-4| - |3x+3| = 4 这类含一个以上绝对值的方程。

## 先点破一件事（她的老毛病会在这里复发）

去绝对值时，如果式子本身是负的，就要**整个变号**：
|a| = a（a ≥ 0）；|a| = -a（a < 0）。

比如 x < -1 时，3x+3 < 0，所以 |3x+3| = -(3x+3) = -3x-3。
这一步的"变号"正是她负号问题的复发点，要专门盯。

## 方法：零点分段法（四步）

### 第 1 步：找零点
让每个绝对值里的式子 = 0：
- 2x-4 = 0 → x = 2
- 3x+3 = 0 → x = -1

### 第 2 步：零点分段
两个零点 -1、2 把数轴切成三段：
x < -1，-1 ≤ x < 2，x ≥ 2
（建议画数轴，让她"看见"三段，标出 -1 和 2 两个断点。）

### 第 3 步：逐段去绝对值 → 解方程 → 检验落点

段①：x < -1
- 2x-4 < 0 → |2x-4| = -(2x-4) = -2x+4
- 3x+3 < 0 → |3x+3| = -(3x+3) = -3x-3
- 方程：(-2x+4) - (-3x-3) = 4 → -2x+4+3x+3 = 4 → x+7 = 4 → x = -3
- 检验：-3 < -1 ✓ → 保留

段②：-1 ≤ x < 2
- 2x-4 < 0 → -2x+4
- 3x+3 ≥ 0 → 3x+3
- 方程：(-2x+4) - (3x+3) = 4 → -2x+4-3x-3 = 4 → -5x+1 = 4 → -5x = 3 → x = -3/5
- 检验：-1 ≤ -3/5 < 2 ✓ → 保留

段③：x ≥ 2
- 2x-4 ≥ 0 → 2x-4
- 3x+3 > 0 → 3x+3
- 方程：(2x-4) - (3x+3) = 4 → 2x-4-3x-3 = 4 → -x-7 = 4 → -x = 11 → x = -11
- 检验：-11 ≥ 2 ✗ → 舍去

### 第 4 步：汇总答案
x = -3 或 x = -3/5

（可让她把两个解都代回原式验算，确认都成立。）

## 三个防错要点

1. 去绝对值变号（负号问题复发点）：-(2x-4) 要拆成 -2x+4；-(-3x-3) 要拆成 +3x+3。
2. 解出来必须检验落点：最高频丢分点——段③解出 x=-11 却不在 x≥2 里，必须舍掉。
3. 边界归属要固定：习惯上 -1 ≤ x < 2（等号放左边）、x ≥ 2（等号放右边），别漏别重。

## 练习（由易到难，答案在最后）

1. |x-1| = 3
2. |x+1| - |x-2| = 1
3. |2x-4| + |3x+3| = 7

## 答案

1. x = 4 或 x = -2
2. x = 1
3. x = -6/5 或 x = 0
