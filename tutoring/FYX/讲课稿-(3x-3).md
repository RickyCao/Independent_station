# 讲课稿：讲透 -(3x-3) 去括号

> 目标：让 FYX 理解"负号去括号要变号"的**原理**，而非死背。约 15-20 分钟，适合一对一。

## 第 0 步 · 暖场回测（2 分钟）

师："上次我们说，减法能怎么变成加法？举个例子：5 - 3 可以写成什么？"

- 能答（"5 加负 3" / "5+(-3)"）→ 表扬并继续。
- 答不出 → 停下来先讲清 **a - b = a + (-b)**，否则后面全白讲。

师（关键句）："记住：**减一个数，就是加它的相反数**。这是今天的地基。"

## 第 1 步 · 先用数字，别碰字母（5 分钟）

师："先不算 x，看纯数字的：-(5 - 3) 等于几？"

引导先算括号内：5 - 3 = 2，所以 -(5-3) = **-2**。

师（故意下套）："那直接拆括号，拆成 -5 - 3，对不对？"

- 她说"对" → 让她算：-5 - 3 = -8，但刚才答案是 -2，两个不一样，所以"直接抄"是错的。
- 她说"不对" → 追问"那该怎么拆？"

师（纠正示范）：
"-(5-3) 就是『0 减去 (5-3)』。
减去 (5-3)，等于减去 5，再减去 -3。
减去 -3，就是加上 3。
所以 0 - 5 + 3 = -2。✓ 和刚才一样。"

师（关键句，放慢）："看，括号里的 -3 拆出来变成 +3。**因为括号前的负号，让里面每一项的符号都翻过来。**"

板书：
```
-(5 - 3) = -5 + 3 = -2
        （不是 -5 - 3！）
```

## 第 2 步 · 三种讲法，让她挑一个（8 分钟）

同一件事，三种角度轮着讲，讲完问她哪个最顺。

**角度 A：乘法（推荐，最严谨）**
```
-(5-3) = -1 × (5-3)
       = -1×5 + (-1)×(-3)
       = -5 + 3
```
关键："负负得正"，所以 (-1)×(-3) = +3。

**角度 B：减法**
```
-(5-3) = 0 - (5-3)
       = 0 - 5 + 3
       = -5 + 3
```

**角度 C：实物（欠债，最直观）**
"把 (5-3) 看成一个包，里面有『5 块钱』和『欠 3 块钱』。
现在『把这个包整个去掉』——
去掉 5 块，同时把欠的 3 块还掉（还债 = 多出 3 块）。
所以结果 = -5 + 3。"

师："三种里哪个最顺？" → 让她**用自己的话复述**她选的那个。能复述 = 懂了。

## 第 3 步 · 过渡到字母（3 分钟）

师："现在把 5 换成 3x，变成 -(3x - 3)。"

让她照选的角度自己拆，**每一步都写出来，不许跳步**：
```
-(3x-3) = -1 × (3x-3)
        = -1×3x + (-1)×(-3)
        = -3x + 3
```
重点确认：+3x 变成 -3x，-3 变成 +3。

## 第 4 步 · 固化规则 + 拦截错误（3 分钟）

师（总结）：
"括号前是**负号**，去括号时**每一项都要变号**：正变负、负变正。
括号前是**正号**（或没符号），原样去，不变号。"

板书：
```
+(a-b) = a - b
-(a-b) = -a + b
```

**三个高频错误，提前拦截**：
1. 只变第一项 → -(3x-3) 错写成 -3x-3（漏了 -3 变 +3）
2. 没负号也乱变 → (3x-3) 错写成 -3x+3
3. -(-x) 拆错 → -(-x) = +x（负负得正）

口诀："**有负号才全变，没负号原样去。**"

## 第 5 步 · 即时练习（3 分钟）

逐题口述理由：
1. -(x + 2) = ?
2. -(2x - 5) = ?
3. -(-x + 1) = ?（这题会卡，盯 -(-x) = +x）
4. 5 - (3x - 3) = ?（先拆括号再加）

## 收尾（1 分钟）

"今天只记一件事：**括号前有负号，里面每个符号都翻。** 回去每天做 3 道符号题，错一道就回来问我为什么。"
